01 · Google Docs metadata

Paste your metadata doc.

Use a normal Google Docs sharing link. Set the document to Anyone with the link · Viewer so MetaMorph can read it.

Waiting for link
Tạo Google Docs từ PDF gốc ↗

1. Tải tất cả PDF gốc (ví dụ 10 file) lên ChatGPT cùng prompt bên dưới.

2. ChatGPT đọc metadata từng PDF, tạo một Google Docs online và trả link. Mỗi file có một khối riêng, tên file giữ nguyên.

3. Chỉnh PDF bằng Affinity, giữ nguyên tên file. Bật chia sẻ Google Docs: Bất kỳ ai có đường liên kết · Người xem, rồi dán link vào MetaMorph.

Lưu ý: Chỉ dùng metadata đọc được từ PDF gốc. MetaMorph hiện khôi phục các trường đã hỗ trợ; muốn xác nhận toàn bộ properties giống gốc, cần đối chiếu PDF gốc và PDF final bằng trình đọc PDF.

Restore policyMetaMorph restores Created, Modified, Application, PDF Producer, and clears Title only when the source record explicitly says it was blank. Other fields in the Doc are ignored.
ImportantUse the regular share URL containing /document/d/…/edit. Published /d/e/…/pub links are not supported.
